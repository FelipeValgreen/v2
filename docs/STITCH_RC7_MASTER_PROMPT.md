# GOOGLE STITCH — RINON RC.7 MASTER DESIGN PROMPT

## Objetivo
Diseñar la experiencia visual y responsive de RINON RC.7 sin cambiar la arquitectura SEO, las URLs propietarias ni la identidad de marca definida. El resultado debe sentirse como el sitio de un fabricante metalmecánico chileno real, contemporáneo, confiable y capaz; nunca como una plantilla, una maqueta de ingeniería o una web generada automáticamente.

## Marca
- Nombre: RINON
- Industria: fabricación y soluciones metálicas
- Taller: San Bernardo, Región Metropolitana, Chile
- Paleta base: #111315, #384148, #F7F7F5, #FFFFFF, acento #F58220
- Tipografía: Raleway
- Identidad: geometría modular, fuerte, sobria, industrial premium
- No usar azul de enlace, gradientes tecnológicos, vidrio futurista, neón ni estética SaaS.

## Principio visual
Prioridad visual obligatoria:
1. evidencia real RINON;
2. fotografía contextual fotorrealista técnicamente plausible;
3. detalle de producto/proceso;
4. diagrama técnico solo como capa explicativa secundaria.

Nunca usar un diagrama técnico como única evidencia de una landing comercial.

## Proyectos a medida
URL técnica permanece /fabricacion-metalica pero la interfaz visible debe decir “Proyectos a medida”.

Hero:
Eyebrow: PROYECTOS A MEDIDA · SAN BERNARDO
H1: “Tu proyecto en metal, hecho a medida.”
Copy: “No necesitas llegar con todo resuelto. Una foto, plano, croquis, muestra o algunas medidas pueden ser suficientes para empezar.”

CTA primaria: Cotizar proyecto

- Plano o croquis

## Responsive
Diseñar y validar explícitamente:
320, 360, 375, 390, 430, 768, 1024, 1280, 1366, 1440, 1600, 1920 px.

En mobile:
- logo siempre visible;
- textos no microscópicos;
- botones >=44 px;
- no overflow horizontal;
- imágenes no deformadas;
- no teléfono quebrado;
- menú orientado a tareas;
- CTA sticky WhatsApp/Cotizar.

En desktop:
- eliminar dock flotante redundante;
- CTA vive en header.

## Copy
Hablar primero desde la necesidad del cliente.
Reducir repetición de:
- requerimiento;
- alcance;
- evaluación;
- factibilidad;
- fabricación metálica.

Preferir:
“Envíanos una foto, plano o medidas. Revisamos qué se puede fabricar y te indicamos qué falta para cotizar.”

en lugar de:
“Evaluamos el requerimiento y alcance antes de fabricar.”
